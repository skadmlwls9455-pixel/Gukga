# 백야선

빙하기 벙커, 군 수색대, AI 연구소에서 퍼진 크리처를 다루는 카드·텍스트 서사 생존 게임. `docs/design-v0.3.md` 기획안을 바탕으로 한 첫 출격 프로토타입이다.

## 실행

빌드 없음. `index.html`을 브라우저로 열면 된다.

## 들어 있는 것

- 출격 1 「식어가는 선」 카드 6장: 출발과 장비 선택, 설피, 등화, 한 자리(C1), 추격 확인, 귀환
- 자원 H 열 · S 보급 · R 분대 · P 추적, 난방 방식(끄기/저출력/고출력) + 명령 합산 비용 검사와 잠금
- 분대 붕괴(R 0) 시 도윤 사망과 회수 실패 처리
- 귀환 H에 따른 밤 판정, 공동 보조 난방, 야간 충전, 출격 2 출발 준비(정기 지급, 작업자 도움, 현장 치료, 도윤 부상 치료)
- 기획안 10절의 계산 예시 A·B 경로는 표와 같은 수치가 나온다

출격 2~4와 C2~C4, 결말 세 개는 아직 없다. 기획안이 첫 출격 6장 검증을 먼저 하도록 정해 두었다.
