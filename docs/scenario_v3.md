# 국가 (國家)
### 게임 기획서 v3

> 구 가제: 버림받은 대통령

**v3 변경 요약**
- 제목 『국가』: 주인공은 대통령이 아니라 나라
- 지표 양 끝 사망 삭제 → 바닥은 몰락, 위쪽은 **불균형 위기**

- 카드 등장 규칙, 조언자 기록, 세력 상태 표시, 선거 구체화

## 0. 콘셉트

대통령은 길어야 8년. 나라는 남는다.

플레이어는 대통령을 차례로 맡으며 한 나라의 60년을 만든다. 한 대통령의 결정은 다음 대통령의 현실이 되고, 사람들의 기억은 다음 대통령에게 짐이 되거나 무기가 된다.

대통령의 이름과 성별은 매번 플레이어가 정하거나 무작위로 정해진다.

### 핵심 원칙
1. **주인공은 나라다.** 대통령은 지나간다. 남는 건 기반과 기억이다.
2. **영웅과 악당은 같은 사람이다.** 같은 결정이 누군가에겐 구원으로, 누군가에겐 배신으로 기억된다.
3. **과거는 끝나지 않는다.** 전임자의 결정은 청구서로, 전임자에 대한 기억은 압력으로 돌아온다.

### 세 개의 층

| 층 | 무엇 | 정권이 바뀌면 |
|---|---|---|
| 나라 | 지표 4개, 발전 단계, 기반, 플래그 | 그대로 이어진다. 교체 방식에 따라 사건이 생긴다 |
| 태도 | 세력 6개가 *지금* 대통령을 어떻게 보는가 | 새 대통령에게는 '관망'에서 다시 시작 |
| 기억 | 세력 6개가 *지난* 대통령들을 어떻게 기억하는가 | 대통령마다 따로 남는다. 흐려지고, 사건이 다시 쓴다 |

## 1. 화면

- **지표 4개**: 막대 + 숫자
- **세력 6개**: 아이콘 + 상태 단어 (숫자 없음)
- **헤드라인 띠**: 세력 상태가 바뀔 때 뜨는 한 줄 뉴스
- **나라 패널**: 연도, 발전 단계, 보유 기반
- **카드**: 상황 줄 + 화자 + 좌우 선택
- **역대 대통령**: 대통령이 바뀔 때 열리는 초상화 줄

## 2. 지표

| 지표 | 몰락 조건 | 몰락 |
|---|---|---|
| 민심 | 0 | **혁명** |
| 경제 | 0 | **국가 부도** |
| 국제신뢰도 | 0 | **국제 고립** |
| 부패도 | 100 | **포획된 국가**: 결정이 대통령궁 밖에서 내려온다 |

- 몰락은 대통령의 끝이지 나라의 끝이 아니다. 다음 대통령이 몰락한 나라를 받는다 (7장).
- 위쪽 끝에서는 죽지 않는다. 대신 지표의 **조합**이 위기를 만든다.

### 불균형 위기

숫자를 50에 맞추는 게임이 아니다. 지표의 조합이 나라의 체질이다. 경제 90에 부패도 15면 선진국이고, 경제 90에 부패도 80이면 터지기 직전이다.

| 위기 | 조건 | 일어나는 일 |
|---|---|---|
| 거품 | 경제 75↑ & 부패도 60↑ | 특혜 대출과 부동산 과열. 위기 카드 3장 안에 수습 못 하면 경제 -40 |
| 불평등 폭발 | 경제 70↑ & 민심 30↓ | 총파업 연쇄. 서민 상태가 카드마다 내려감 |
| 열광 | 민심 85↑ & 제도 기반 2개 이하 | 개헌·종신 집권 요구 카드. 받아들이면 임기 제한이 사라진다 |
| 원조 의존 | 국제신뢰도 75↑ & 경제 30↓ | 원조가 예산의 절반. 정책 조건 카드가 대사관에서 온다 |
| 고립된 자존심 | 민심 70↑ & 국제신뢰도 25↓ | 제재 속 결집. 민심은 버티지만 경제가 매 임기 -5 |
| 숙청의 계절 | 한 임기에 부패도 30 이상 하락 & 군부 또는 재계 '적대' | 쿠데타 조짐 연쇄. 막지 못하면 **개혁가의 죽음** |
| *선진 안정* | 경제 80↑ & 부패도 25↓ & 민심 50↑ | 위기 카드 빈도 감소. OECD 심사 가산 |

- 위기는 끝이 아니라 카드 연쇄다. 수습하면 지나가고, 못 하면 몰락으로 간다.
- 중앙은행 독립 기반이 있으면 거품 조건이 경제 85↑로 늦춰진다.

## 3. 발전 단계와 기반

OECD는 수치를 달성한 결과가 아니라 나라를 단계별로 쌓아 올린 결과다. 대통령마다 다른 시대의 문제를 맡는다.

| 단계 | 이 시대의 문제 | 다음 단계 조건 |
|---|---|---|
| 1. 생존 | 식량, 치안, 재정 | 생존 기반 2/3 + 경제 35↑ |
| 2. 산업화 | 공장, 전력, 도로, 노동 | 산업 기반 3/5 + 경제 55↑ |
| 3. 제도화 | 교육, 사법, 행정, 과거사 | 제도 기반 4/6 + 경제 65↑ + 부패도 45↓ |
| 4. 문턱 | 생산성, 사회안전망, 국제협약 | 선진 기반 2/3 + 심사 조건 → **OECD 심사** |

- 단계마다 카드 풀이 다르다. 생존 단계에서 연금 개혁 카드는 나오지 않는다.
- 기반은 단계와 상관없이 얻을 수 있다. 단계 조건을 셀 때만 범주가 중요하다.
- 기반을 잃어 조건이 깨지면 한 단계 **후퇴**한다.

### 기반

기반은 나라에 남는 것들이다. 대통령이 바뀌어도 사라지지 않는다. 쿠데타, 내전, 부도로 잃을 수 있고, 제도 기반은 **장악**되어 효과가 꺼질 수 있다 (후임자가 복원 가능).

기반에는 만든 대통령의 이름이 붙는다 (6장 재평가).

| 범주 | 기반 | 매 임기 효과 |
|---|---|---|
| 생존 | 곡물 비축망 | 식량 위기 피해 절반 |
| | 치안 회복 | 민심 +3 |
| | 통화 안정 | 경제 위기 피해 -5 |
| 산업 | 전력망 | 경제 +3 |
| | 제철소 | 경제 +3, 재계 +5 |
| | 수출 공단 | 경제 +4, 국제 +2, 공장 사고 위험 |
| | 고속도로 | 경제 +2, 변방 +5 |
| | 항구 | 경제 +2, 국제 +2 |
| 제도 | 국립대학 | 세 임기 뒤부터 경제 +3, 광장 +5 |
| | 독립 법원 | 부패도 -3, 비상조치류 카드 비용 증가 |
| | 선거관리위원회 | [개표] 카드 사라짐 |
| | 중앙은행 독립 | 거품 조건 완화 |
| | 반부패청 | 부패도 -4, 보고 수치 흐림 해제 |
| | 노동감독청 | 공장·제철소 사고 확률 절반 |
| 선진 | 국민건강보험 | 민심 +4, 경제 -2 |
| | 국민연금 | 민심 +2, 세 임기 뒤부터 경제 +2 |
| | 국제협약 (무역·노동·환경 중 2) | 국제 +5 |
| 특수 | 유전 | 경제 +5, 부패도 +3 |
| | 학교 급식 (8년 이상 시행 시) | 서민 +5, OECD 심사 가산 |

### 기반을 얻는 길
- **[예산] 카드** (필수, 2년마다): 기반 투자와 세력 달래기 중 하나를 고른다. 기반 대부분은 투자 2회로 완성된다.
  > 재무장관: "올해 예비비로는 하나만 됩니다."
  > ← 전력망 착공 (진행 1/2) / → 장교 봉급 인상 (군부 ▲▲)
- **기회 카드**: [제철소]처럼 한 장으로 바로 얻지만 조건이 붙는다.
- **연쇄**: 어떤 선택을 오래 유지하면 생긴다 (학교 급식).

## 4. 세력

| 세력 | 누구 | 원하는 것 |
|---|---|---|
| 군부 | 장교단, 참모본부 | 질서, 예산, 면책 |
| 재계 | 재벌, 지주, 외국 자본 | 성장, 특혜, 조용한 노조 |
| 서민 | 노동자, 농민, 도시 빈민 | 빵값, 일자리, 아이들 급식 |
| 광장 | 학생, 기자, 지식인 | 자유, 진실, 처벌 |
| 구세력 | 전 정권 지지층, 종교계, 지방 유지 | 전통, 체면, 그때의 영광 |
| 변방 | 산악민족, 북부, 소수민족 | 땅, 자치, 잊히지 않기 |

### 상태 표시: 숫자 대신 단어와 헤드라인

| 상태 | 범위 |
|---|---|
| 적대 | -60 이하 |
| 불만 | -59 ~ -20 |
| 관망 | -19 ~ +19 |
| 호의 | +20 ~ +59 |
| 열광 | +60 이상 |

카드 표기: ▲ = +10, ▲▲ = +20, ▼ = -10, ▼▼ = -20

상태가 바뀌면 헤드라인 띠에 한 줄이 뜬다.

| 세력 | 내려갈 때 | 올라갈 때 |
|---|---|---|
| 군부 | 장교 클럽에서 대통령 사진이 내려갔다. | 국군의 날 사열에서 박수가 길었다. |
| 재계 | 그룹 세 곳이 투자 계획을 보류했다. | 회장단이 오찬 초청에 전원 참석했다. |
| 서민 | 시장 상인들이 대통령 달력을 떼어냈다. | 택시 기사들이 라디오 연설을 끝까지 틀었다. |
| 광장 | 대학가에 대자보가 붙기 시작했다. | 신문 사설이 처음으로 '용기'라는 단어를 썼다. |
| 구세력 | 대주교가 성탄 미사 초청을 취소했다. | 지방 유지들이 기념비 모금을 시작했다. |
| 변방 | 북부 도로에 검문소가 생겼다. 반군의 것이었다. | 산악 마을 학교에 대통령 사진이 걸렸다. |

카드를 내미는 화자의 표정도 그 세력의 상태를 따른다.

### 극단의 압력

| 세력 | 적대 | 열광 |
|---|---|---|
| 군부 | 쿠데타 조짐 카드 | 장성들이 내각 자리를 요구 |
| 재계 | 자본 탈출, 경제 카드마다 -2 | 회장이 장관을 추천하기 시작 |
| 서민 | 폭동 | 민심 하락폭 절반 (대신 열광 위기가 쉬워짐) |
| 광장 | 총파업, 외신 비판 | 언론이 실수를 덮기 시작, 부패도 서서히 상승 |
| 구세력 | 종교계 파문, 지방 반란 | 전 독재자 복권 운동이 대통령 이름을 빌림 |
| 변방 | 분리 독립 운동 | 다른 세력들이 '변방 편애'라며 반발 |

## 5. 국가 선택

### 🟡 아란도 공화국 (난이도: ★★☆☆☆)
> 한때 대륙의 곡창지대였으나 포퓰리즘 정권이 수십 년간 이어지며 만성 재정 적자에 시달리는 나라.
> 국민들은 "예전엔 잘 살았는데"를 입버릇처럼 달고 산다.

- 지표: 민심 55 / 경제 35 / 부패도 60 / 국제신뢰도 45
- 단계: 산업화 (간신히)
- 기반: 곡물 비축망, 치안 회복, 항구, 국립대학
- 시작 세력: 군부 관망 / 재계 관망 / 서민 호의 / 광장 관망 / 구세력 호의 / 변방 관망
- 특수 카드: `외채 협상`, `포퓰리즘 선언`, `농업 국유화`
- 모티프: 아르헨티나 + 브라질

### 🔴 살리나스 연방 (난이도: ★★★☆☆)
> 풍부한 천연자원을 가졌으나 독재 왕조가 3대째 이어지다 붕괴한 직후.
> 자원은 있는데 분배 구조가 완전히 망가져 있다.

- 지표: 민심 40 / 경제 50 / 부패도 75 / 국제신뢰도 30
- 단계: 생존 (돈은 있는데 기초가 없다)
- 기반: 유전, 항구
- 시작 세력: 군부 호의 / 재계 관망 / 서민 불만 / 광장 관망 / 구세력 호의 / 변방 불만
- 특수 카드: `석유 국유화`, `자원 민영화 협상`, `전 독재자 재판`
- 모티프: 베네수엘라 + 필리핀

### 🔵 코르바니아 인민공화국 (난이도: ★★★★★)
> 냉전 시절 사회주의 노선을 택했다가 고립된 섬나라.
> 의료와 교육 수준은 높지만 경제는 바닥이고, 서방의 제재가 수십 년째 이어지고 있다.

- 지표: 민심 60 / 경제 20 / 부패도 40 / 국제신뢰도 15
- 단계: 생존 (의료는 문턱, 경제는 생존)
- 기반: 치안 회복, 국립대학, 국민건강보험
- 시작 세력: 군부 호의 / 재계 불만 / 서민 관망 / 광장 불만 / 구세력 호의 / 변방 관망
- 특수 카드: `개혁개방 선언`, `제재 해제 협상`, `망명자 귀환 프로그램`
- 모티프: 쿠바 + 북한(경제)

## 6. 유산: 기억이 다음 대통령을 움직인다

### 유산 기록
대통령이 끝나면 **유산 카드**가 남는다.
- 이름, 재임 연도, 끝난 방식
- 세력별 기억값 = 퇴임 순간 그 세력의 상태값
- 대표 플래그 최대 3개 (세력을 가장 크게 움직인 결정)
- 만든 기반

### 규칙 ① 계승 압력
카드가 전임자의 대표 플래그나 기반을 건드리면:
- 그 전임자를 +50 이상으로 기억하는 세력의 반발 ×1.5 (+80 이상이면 ×2)
- -50 이하로 기억하는 세력은 청산하는 쪽에 ▲ 보너스

> 예: 전임자가 서민에게 '우리 대통령'이고 `급식`이 대표 플래그다. 후임자가 급식을 줄이면 서민 ▼▼가 ▼▼▼가 되고, 급식실 앞에 전임자 사진이 붙는다.

### 규칙 ② 소환
세력이 '적대'가 되면, 그 세력이 가장 높게 기억하는 전임자의 이름이 카드 대사와 헤드라인에 등장한다.
> "제3대 대통령은 장교들을 이렇게 대하지 않았다."

### 규칙 ③ 재평가
기억은 고정되지 않는다. 사건이 다시 쓴다.

| 사건 | 효과 |
|---|---|
| 전임자가 만든 기반이 위기를 막음 | 그 전임자의 재계·서민 기억 +15 |
| 진실 공개 ([명단], 매장지 발굴) | 해당 전임자의 광장·서민·변방 기억 -20 |
| 후임자가 전임자 정책을 폐지 | 그 정책 수혜 세력의 기억 +10 ("그때가 좋았지") |
| [동상] 철거 | 기리는 쪽 기억 +10, 미워하는 쪽 -10 (철거는 기억을 지우지 않고 갈라놓는다) |
| [계승]에서 정책을 이음 | 그 정책을 아끼는 세력의 기억 +10 |

### 규칙 ④ 흐려짐
대통령이 한 명 바뀔 때마다 모든 기억값 ×0.8. 재평가 사건이 다시 선명하게 만든다.

### 역대 대통령 화면
대통령이 바뀔 때 열린다. 초상화가 줄지어 있고 각자 지금의 칭호가 붙어 있다. 재평가가 일어나면 칭호가 바뀌고, 동상이 서거나 철거된다.

## 7. 정권 교체: 이월 공식 대신 사건

나라의 지표와 기반은 그대로 다음 대통령에게 간다. 바뀌는 건 교체 방식이 일으키는 사건뿐이다.

| 교체 방식 | 즉시 변화 | 새 대통령 세력 시작 | 첫 카드 |
|---|---|---|---|
| 임기 만료·선거 패배 | 없음 | 전원 관망 | [계승] |
| 혁명 | 민심 60으로, 경제 -15 | 광장·서민 호의, 재계 적대 | [혁명 재판] |
| 쿠데타 | 국제 -20, 선관위·독립 법원 장악 | 군부 열광, 광장 적대 | [군정 이양]: 새 대통령은 군복을 입고 시작 |
| 국가 부도 | 경제 15로, 통화 안정 상실 | 재계 불만 | [IMF] 강제 |
| 국제 고립 | 국제 10으로 | 구세력 호의 | [제재 해제 협상] |
| 포획된 국가 | 부패도 80으로 | 재계 열광, 광장 적대 | [재계의 후보] |

- 전임자의 플래그는 그대로 넘어온다. 전임자의 청구서는 후임자에게 온다.
- 청구서는 한 임기에 4장까지. 넘치는 건 그다음 대통령에게 간다.
- 조언자는 [계승]에서 유임하거나 경질할 수 있다. 유임하면 약속 기록도 이어진다.

## 8. 카드 설계 원칙

1. **공짜 선택은 없다.** 양쪽 모두 잃는 게 있다.
2. **누가 웃고 누가 우는가.** 모든 선택은 최소 한 세력을 올리고 한 세력을 내린다.
3. **두 개뿐인 이유를 보여준다.** 상황 줄에 제약을 넣는다: 기한, 장악된 기관, 화자의 거부, 돈. 플레이어가 "왜 다른 방법은 없지?"라고 묻기 전에 답이 있어야 한다.
4. **결과는 나라 상태에 따라 갈린다.** 같은 선택도 부패도·기반·세력에 따라 수치와 문장이 달라진다. 비극을 그 자리에서 확정하지 않는다.
5. **조언자는 중립이 아니고, 기록이 남는다.** (10장)
6. **결과 문장은 판정하지 않는다.** 일어난 일만 쓴다. 선택을 꾸짖는 듯한 문장은 쓰지 않는다.
7. **카드 유형을 섞는다.** 딜레마만 이어지면 공식이 보인다.

> 검수 기준: 카드를 읽자마자 "착한 쪽"을 고를 수 있으면 다시 쓴다. "왜 이것밖에 못 하지?"가 먼저 떠올라도 다시 쓴다.

### 카드 유형

| 유형 | 무엇 | 임기당 목표 |
|---|---|---|
| 필수 | 교체·예산·선거 | 4~5 |
| 딜레마 | 둘 다 대가가 있는 선택 | 4~5 |
| 청구서 | 과거 결정의 결과가 돌아옴 | 최대 4 |
| 기회 | 크게 얻지만 조건이 붙음 | 1 |
| 신뢰 | 누구 말을 믿을 것인가 | 1 |
| 유산 | 전임자의 기억과 부딪힘 | 0~2 |
| 숨 고르기 | 작은 결정, 위트 | 1 |

## 9. 카드 등장 규칙

- 임기당 14장.
- **필수**: 임기 첫 카드(교체 카드), [예산] 2장(2년마다), 임기 말 [선거] 연쇄 1~2장.
- **조건 카드**: 지표, 플래그, 세력 상태, 발전 단계, 기반으로 발생.
- **일반 카드**: 현재 단계의 풀에서 가중 무작위. 세력 상태가 나쁠수록 그 세력 화자의 카드가 자주 나온다.
- **우선순위**: 위기 > 교체 > 청구서 > 유산 > 필수 > 일반
- **반복 방지**: 같은 카드는 대통령 한 명당 한 번. 같은 화자는 연속 2장까지.

## 10. 조언자와 정보

### 고정 인물

| 인물 | 연줄 | 경향 (숨김) |
|---|---|---|
| 비서실장 | 재계 (회장의 처남) | 나쁜 소식을 축소한다 |
| 참모총장 | 군부 | 기한을 짧게 약속한다 |
| 재무장관 | 국제 금융 출신 | 수치는 정확, 판단은 긴축 쪽 |
| 내무장관 | 구세력 | 위협을 부풀린다 |
| 민정수석 | 서민·광장 | 정확하지만 늘 늦게 온다 |
| 외신 기자 | 광장 | 질문만 한다 |

### 약속 기록
조언자가 수치나 기한을 약속한 카드는 실제 결과가 기록되고, 그 인물의 다음 카드에 한 줄로 붙는다.
> 기록: 국경 정리 "6주" → 실제 5개월

경향은 숨겨져 있지만 기록이 쌓이면 보인다. 플레이어는 기록을 보고 그 사람 말을 얼마나 믿을지 정한다.

### 부패가 정보를 흐린다
부패도 60 이상이면 경제 막대 옆에 '?'가 붙는다. 보고되는 경제 수치가 실제와 최대 ±10 다를 수 있다. 진짜 값은 위기 때 드러난다. 반부패청이 있으면 해제된다.

## 11. 선거

임기 말 [선거] 연쇄 1~2장 뒤 판정.

**선거 점수 = 민심 + 아래 보정**

| 요소 | 보정 |
|---|---|
| 야권 | 분열 +10 / 보통 0 / 단일화 -10 (공작 카드로 바꿀 수 있음, 부패도 +) |
| 선관위 | 있음: 보정 없음 / 없음: [개표] 카드 등장 |
| 재계 | 호의 이상 +5 (자금) / 적대 -5 |
| 군부 | 적대면 선거 전에 쿠데타 판정 |
| 언론 | `언론법_선례`를 쓴 적 있으면 +5 (대신 광장 ▼) |
| 공약 카드 | [무상 급식] 등 카드별 보정 |

- 50 이상이면 재선, 미만이면 패배.
- 패배하면 **불복**을 고를 수 있다 → 정통성 위기 연쇄 (광장 ▼▼, 국제 ▼▼, 군부가 누구 편에 설지 정하는 카드).
- 패배를 인정하면 광장 기억 +20. 평화롭게 물러난 대통령으로 남는다.
- 재선은 1회. 열광 위기에서 종신 집권을 받아들이면 제한이 사라진다.

## 12. 카드

**표기**
- **상황**: 두 개뿐인 이유
- **지표 / 세력**: 즉시 변화
- **결과**: 선택 직후 문장. `(조건)`이 붙으면 나라 상태에 따라 갈린다
- **연쇄**: 남는 플래그와 돌아오는 카드
- 수치는 1차안. 플레이테스트로 조정한다.

#### [장관 셋] · 딜레마
> 상황: 그는 북부 곡물 창고 열두 곳을 쥐고 있다. 대신할 유통망은 없다.

- 연쇄: `조용한_퇴장` → 다음 대통령 때 외신 기자가 그 돈의 행방을 묻는다.

- 결과 (노동감독청 있음): "용광로에 불이 들어왔다. 첫해 사고 보고서는 두 쪽이었다."

| 인권 | 독립 법원, 과거사 | `비상조치`, `산간_작전`, `언론법_선례` |
| 사회 | 선진 기반, 학교 급식 | — |

- 걸리는 플래그가 있으면 그 위원회 카드에서 **시정**과 **해명** 중 하나를 고른다. 시정은 비싸고, 해명은 통과 확률이 낮다.
  > 노동 위원회 심사관: "노조가 금지된 제철소가 아직 있습니까?"
  > ← 독점 조기 해제 (경제 -10, 재계 ▼▼, 통과) / → "계약은 계약입니다." (통과 확률 30%)

#### [외신 기자] · 퇴임
대통령의 마지막 카드. 질문은 대표 플래그 중 가장 무거운 것으로 정해진다.
- `산간_작전`: "산간 마을 작전 당시 민간인 피해 보고를 받으셨습니까?"
- `제철소_독점`: "용광로에서 다친 노동자들의 이름을 아십니까?"
- `급식`: "그 급식값, 결국 다음 세대가 갚는 것 아닙니까?"
- `비상조치`: "교도소에 있는 사람 중 무고한 사람은 몇 명입니까?"
- `조용한_퇴장`: "물러난 장관의 해외 계좌에 대해 알고 계셨습니까?"
- 플래그 없음: "임기 중 가장 후회하는 결정은 무엇입니까?"

답에 따라 마지막으로 세력 상태가 움직이고, 그 값이 유산 기억값이 된다.

## 13. 엔딩

### 대통령의 끝 → 유산 카드
끝난 방식(임기 만료 / 선거 패배 / 혁명 / 쿠데타 / 부도 / 고립 / 포획 / 개혁가의 죽음) + 회자 칭호 + 교과서 한 줄.

### 회자 칭호

| 세력 | 기억 +50 이상 | 기억 -50 이하 |
|---|---|---|
| 군부 | 강철의 손 | 군을 판 사람 |
| 재계 | 경제 대통령 | 곳간을 턴 사람 |
| 서민 | 우리 대통령 | 저들의 대통령 |
| 광장 | 민주주의의 기적 | 독재자 |
| 구세력 | 나라의 어른 | 뿌리를 뽑은 사람 |
| 변방 | 처음 우리를 본 사람 | 수도의 대통령 |

- -49 ~ +49는 칭호 없이 한 줄: "그런 대통령도 있었지."
- 칭호는 재평가에 따라 바뀐다. 역대 대통령 화면에는 *지금* 칭호가 보인다.

### 특수 칭호

| 조합 | 칭호 |
|---|---|
| 서민 +50↑ & 광장 -50↓ | 사랑받은 독재자 |
| 광장 +50↑ & 서민 -50↓ | 박수받은 엘리트 |
| 군부 +50↑ & 재계 +50↑ & 광장 -50↓ | 개발 독재 |
| 몰락으로 끝남 & 광장·서민 +50↑ | 순교자 |
| 전 세력 ±30 이내 | 그냥 그런 대통령 |
| 전 세력 -30↓ | 모두가 미워한 사람 |

### 나라의 끝 (게임 종료)

| 끝 | 조건 |
|---|---|
| **가입** | OECD 심사 통과 |
| **60년** | 시간 소진. 도달한 단계로 기록된다 (생존: 버티는 나라 / 산업화: 공장의 나라 / 제도화: 문턱 앞의 나라 / 문턱: 거의 다 온 나라) |
| **실패 국가** | 몰락 3연속, 또는 생존 기반 전부 상실 |

최종 화면: 역대 대통령 줄(최종 칭호) + 나라의 교과서 한 단락.
> "아란도 공화국. 제3대 때 제철소를 세웠고 제5대 때 광장 사태를 겪었다. 제8대 때 OECD에 가입했다. 제3대 대통령의 동상은 두 번 철거되고 한 번 다시 섰다."

## 14. 검증판: 먼저 만들 것

카드 50장보다 먼저, 12장으로 서로 다른 역사가 나오는지 확인한다.

- **나라**: 아란도 (산업화 시작)
- **대통령**: 3명, 임기당 카드 8장 (재선 없음)
- **카드 12장**: [장관 셋] [IMF] [비상조치] [제철소] [제철소 노조] [3만 명의 줄] [무상 급식] [급식 재원] [급식 축소] [동상] [계승] [두 개의 보고서] + [예산]
- **시스템**: 지표 4 / 세력 6 / 기반 5개 (제철소, 수출 공단, 노동감독청, 국립대학, 통화 안정) / 유산 규칙 ①③ / 교체는 평화적 교체와 부도만

### 검증 질문
1. 다섯 번 플레이하면 대통령 셋의 칭호 조합이 다섯 번 다 다른가?
2. 플레이어가 숫자 맞추기보다 "이 나라를 어떤 나라로 만들지"를 고민하는가?
3. 2대·3대 대통령이 전임자 때문에 곤란해진 순간이 한 번 이상 있는가?
4. 다섯 번째 판쯤 결과 문장의 공식이 보이는가?

### 기대하는 한 판: 3대에 걸친 제철소
1. **제1대**: [제철소] 수락. 경제가 오르고, 재계는 '경제 대통령', 광장은 '독재자'라 부른다.
2. **제2대**: [계승]에서 정리. [제철소 노조] 신고 수리. [동상] 철거. 재계의 기억 속 제1대는 오히려 더 선명해진다.
3. **제3대**: 부도 위기. 제철소 기반이 경제 피해를 막는다 → 제1대의 재계·서민 기억 +15. [동상]이 재건립 청원으로 다시 뜬다. 이번엔 철거를 반겼던 사람들 중 일부가 서명한다.

이 흐름이 손으로 짠 시나리오가 아니라 규칙에서 저절로 나오면 검증 성공.

## 15. 분위기 / 문체 방향

- 카드 텍스트는 건조하고 짧게. 감정 직접 주입 X.
- 플레이어가 스스로 도덕적 불편함을 느끼게 구성.
- "정답 없음": 독재로 성공해도 엔딩, 민주로 성공해도 엔딩.
- 역사 교과서 같은 톤 살짝. 위트는 카드 결과 설명에서만.
- 결과는 확정이 아니라 단서다. 비극은 나중에, 다른 카드로, 확률로 온다.
- 결과 문장이 선택을 꾸짖지 않게 쓴다.
- 두 박자 문장(얻은 것 하나, 잃은 것 하나)은 가끔만. 매번 쓰면 공식이 보인다.
- 숫자는 구체적으로, 해석은 빼고. "많은 사람이"보다 "4천 명이".
- 화자는 반복 등장하는 인물들. 같은 인물이 쌓이면 대사 한 줄에도 의도가 읽힌다.
